## 📖 How It Works

1. A user registers a new account.
2. The user logs in and receives a JWT access token.
3. Protected API endpoints validate the JWT token.
4. Role-Based Access Control (RBAC) determines whether the user has permission to access the requested resource.
5. Prompt Injection Detection analyzes AI prompts before forwarding them to the language model.
6. Safe prompts are sent to the Groq Llama 3.1 model.
7. AI-generated responses are returned to the user.
8. Audit logs record important system activities for monitoring and security.
